# 介绍 
- 这个代码是用来测试网络的qps的


# 运行 ：
## 先运行服务端

- `./uring_tcp_server` : 用io_uring实现的异步的tcp服务端的可运行文件 ， 端口为9999

- `./epoll_tcp_server` : 用epoll实现的同步的tcp服务端的可运行文件 ， 端口为2048
- 
- 
-  用户在linux中输入  `./test_qps_tcpclient -s 127.0.0.1 -p 2048 -t 50 -c 100 -n 10000`   的命令 
(-s :**目标服务器 IP 地址** ， -p :**目标服务器端口号**，-t  : 创建的客户端的线程数量 ， -c : 创建的连接数  ,  -n : **总请求数 / 总事务数**)
