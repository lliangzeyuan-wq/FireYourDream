```
3\r\n        ← 总共有3组（3个元素）
3\r\n        ← 第1组：字符串长度=3
set\r\n      ← 第1组：读3个字符：s e t
4\r\n        ← 第2组：字符串长度=4
key1\r\n     ← 第2组：读4个字符：k e y 1
6\r\n        ← 第3组：字符串长度=6
value1\r\n   ← 第3组：读6个字符：v a l u e 1
```
